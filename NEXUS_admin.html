Como funciona o treinamento

1. O estudante envia uma pergunta ao assistente.
2. O assistente responde usando a base de regras.
3. O estudante avalia a resposta com 👍 ou 👎.
4. O feedback é registrado aqui.
5. Você cria ou ajusta uma regra com uma resposta melhor.
6. O assistente passa a usar a regra atualizada nas próximas perguntas.
